# Content Review Guide

Use this guide when real Hellocraft project, company, media, contact, or career material is supplied.

## Main rule

Record every supplied item before deciding whether it appears on the website.

```text
receive
→ record
→ group by project/topic
→ check duplicates
→ confirm facts
→ confirm whether it can be public
→ note missing information
→ select what goes on the website
```

A file that is not selected for the website should still remain recorded.

## For portfolio projects

Record whatever is actually known:

```text
project name
public project name if different
what Hellocraft worked on
short project description
client/partner if publishable
year/date if confirmed
public link if available
screenshots/renders/video
credits or publication restrictions
```

Do not guess missing information.

## For media

For each image or video, record:

```text
original filename
related project
what it shows
whether Hellocraft may publish it
required credit if any
quality/resolution notes
```

Do not decide final crops or alt text until the actual media is reviewed.

## For About information

Record only confirmed company information such as:

```text
short company description
what the team regularly works on
public location if desired
approved clients/partners if they may be named
public experience/results if supported
team information only if intentionally public
```

## For contact information

Record only real public channels:

```text
business email
contact form/link if used
public social profiles
public Discord/community link if applicable
```

Do not create placeholder contact details that look real.

## For Careers

Only publish real current openings.

Useful fields:

```text
job title
short description
location
employment/contract type
application link or email
```

No current openings is a valid public state.

## Review labels

Keep labels simple:

```text
Confirmed
→ supported by a reliable source

Partly confirmed
→ some details are confirmed, others are not

Unconfirmed
→ supplied but not yet supported

Conflicting
→ sources disagree
```

For publication:

```text
Public
→ approved to show on the website

Pending approval
→ may be public later, but permission/details are not settled

Internal only
→ keep for project records, not the public website

Unknown
→ publication status has not been decided
```

For use on the website:

```text
Use
Keep for later
Do not use
```

## Important rule

A fact can be true but still not be suitable for public use. Always keep **fact checking** and **publication permission** as separate decisions.
