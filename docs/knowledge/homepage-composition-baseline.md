# Homepage Composition Baseline

Current approved-for-review Homepage composition after the human-design audit.

```text
Hero
→ one sentence-case studio label
→ one dominant display headline
→ concise support copy + one text action
→ one lower/wider media field

Selected Work
→ compact section heading
→ one primary featured project
→ one secondary project with reduced visual weight

Studio
→ one main statement
→ supporting studio copy
→ capability narrative nested as a smaller subsection

Contact
→ compact closing statement + one action
```

Rules:

- do not promote every section to hero-scale typography;
- do not restore global all-caps micro-labels;
- do not restore global balanced heading wrapping;
- do not make portfolio entries equal merely for layout symmetry;
- do not show internal development prose as public-facing dummy copy;
- do not introduce another decorative signature system to manufacture uniqueness;
- real logo and project media should carry most final distinctiveness.

This is a visual review baseline, not rendered production acceptance.
